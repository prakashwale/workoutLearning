# Fit4Life - Modern Fitness Application

A comprehensive, modern fitness application built with HTML, CSS, and JavaScript that provides users with workout tracking, BMI calculation, and fitness guidance.

## 🚀 Features

### Core Functionality
- **User Registration & Login System** - Secure authentication with form validation
- **BMI Calculator** - Calculate and categorize BMI with visual feedback
- **Workout Timer** - Professional stopwatch for tracking workout sessions
- **Workout Categories** - Upper body and lower body workout guides
- **Interactive FAQ** - Click-to-expand fitness questions and answers
- **Workout Types** - Detailed information about Cardio, Strength, Yoga, and Cycling

### Modern Design Features
- **Responsive Design** - Works perfectly on desktop, tablet, and mobile devices
- **Modern UI/UX** - Clean, professional interface with smooth animations
- **Gradient Backgrounds** - Beautiful visual appeal with modern color schemes
- **Interactive Elements** - Hover effects, smooth transitions, and loading states
- **Professional Typography** - Inter font family for better readability
- **Card-based Layout** - Organized content presentation with shadow effects

### Technical Enhancements
- **CSS Custom Properties** - Consistent design system with CSS variables
- **Flexbox & Grid Layout** - Modern CSS layout techniques
- **Smooth Animations** - CSS transitions and keyframe animations
- **Form Validation** - Real-time input validation with user feedback
- **Loading States** - Visual feedback during form submissions
- **Accessibility** - Proper semantic HTML and ARIA labels

## 🔧 Customization

### Colors
Modify the CSS custom properties in the `:root` selector:
```css
:root {
    --primary-color: #2563eb;
    --secondary-color: #10b981;
    /* ... other colors */
}
```

### Fonts
Change the font family in the CSS:
```css
--font-sans: 'Your-Font', sans-serif;
```

### Layout
Adjust grid and flexbox properties for different layouts:
```css
.services-grid {
    grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
}
```
